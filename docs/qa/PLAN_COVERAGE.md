# TEST_PLAN section 4: what reaches each line

Every checkbox in [TEST_PLAN.md](../TEST_PLAN.md) section 4, with the checks that reach it. Written during the November QA pass: each line was read against the tests and routes, and where nothing really reached it a new check was added (the `QaPlan*Tests` files, 185 methods and 275 cases; 67 failed on the first run: 29 real bugs, 29 mistakes in the checks, 9 design calls, all taken).

The verdict is what the map found **before** those checks were written: `covered` means a check already reached it, `partial` that part was reached, `gap` that nothing was, and `human-only` that only a person can judge it. A note's `New:` names the check added for it, so a `gap` with a `New:` is reached now. Later batches added more (`QaFairTests`, `QaFlowTests`, the `Second` and `Third` files), which this table doesn't list line by line.

**193 partial, 80 covered, 80 gap, 32 human-only**
