Do not interpret `stride-directional-red-01`'s contact-only marker as directional presentation acceptance.

## Integrated candidate checks

`stride-directional-correction-03` passes all 96 cases with the original limits: worst drift 4.55 mm, no penetration, maximum contact lift 18.43 mm, maximum reach correction 70.59 mm and minimum shin separation 99.88 mm. The correction turns the lower body with the step, counter-turns the spine for aim, widens the deliberate-step base and preserves outward knee direction. It reverses the locomotion state for back steps; it does not run the entire Animator/action clock backwards. Unity's [state speed multiplier documentation](https://docs.unity.com/en-us/engine/6000.6/script-reference/unityengine/animatorstateinfo/speedmultiplier) describes that distinction.
